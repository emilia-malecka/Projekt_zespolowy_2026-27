# Projekt-zespo-owy-2026-27
Interaktywna aplikacja turystyczna pełniąca funkcję osobistego dziennika podróży. Umożliwia użytkownikom dokumentowanie swoich wyjazdów, wizualizację tras na interaktywnej mapie oraz generowanie szczegółowych statystyk. Projekt realizowany w ramach Projektu Zespołowego 2026/27.
